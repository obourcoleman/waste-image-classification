# Waste Image Classification for Recycling

## Dataset

This project uses the Garbage Classification V2 dataset available on Kaggle:

https://www.kaggle.com/datasets/sumn2u/garbage-classification-v2

## Dataset Description

- 10 waste categories
- RGB images
- Used for image classification using CNN and MobileNetV2

## Models Used

- Custom CNN
- MobileNetV2 (Transfer Learning)

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## How to Run

1. Download the dataset from Kaggle.
2. Upload the dataset ZIP file to Google Colab.
3. Run the notebook cells sequentially.
4. Train the models and generate evaluation results.
